# Fake Streaming Platform 🎬

Este proyecto imita las funcionalidades básicas de una plataforma típica de streaming. El sitio muestra texto e imágenes extraídas de [The Movie Database (TMDb)](https://www.themoviedb.org/?language=en-US).

## 🛠 Tecnologías utilizadas

- [Vue.js](https://vuejs.org/) (con Vite)
- Consumo de API externa: [TMDb API](https://developer.themoviedb.org/)

## 🎯 Objetivo del proyecto

El propósito de este proyecto fue familiarizarme con el uso del framework **Vue.js** y entender su flujo de trabajo, estructura y capacidades al consumir APIs externas.

## ⚠️ Nota

Este sitio es solo con fines educativos y no ofrece contenido de streaming real.
